클래스툴 for Whale 개인정보 처리방침

최종 수정일: 2026-09-25 · 클래스툴 for Whale은 네이버가 만들거나 보증하는 공식 앱이 아닙니다.

클래스툴 for Whale(이하 "확장앱")은 선생님이 학급 도구(뽑기, 타이머 등)를 쓸 수 있도록 학생 명단을 선생님의 브라우저 안에만 저장합니다. 개발자를 포함한 누구에게도 학생 정보가 전송되지 않습니다.

1. 처리하는 정보

학생 이름웨일 클래스에 표시되는 이름(별명) 또는 선생님이 직접 입력한 이름
번호웨일 클래스의 번호(NEIS 정보 등록 시) 또는 자동으로 붙인 번호
그룹웨일 클래스 그룹 이름(있을 때)
웨일 클래스 내부 ID다시 불러올 때 같은 학생을 찾기 위한 식별 번호
도구 사용 기록뽑기 결과 기록, 타이머 설정

처리하지 않는 정보: 이메일, 연락처, 성적, 사진, 위치, 브라우저 방문 기록

2. 수집 방법

  • 선생님이 [웨일 클래스에서 불러오기]를 누르면, 선생님이 로그인한 웨일 클래스의 구성원 관리 화면을 읽기만 합니다. 웨일 클래스의 정보를 바꾸지 않습니다.
  • 선생님이 이름을 직접 입력하거나 붙여넣을 때
  • 처음 불러오기 전에 이 내용을 안내하고 동의를 받습니다.

3. 이용 목적

학급 도구 화면에 학생 이름과 번호를 표시하고, 뽑기의 중복 제외와 기록 기능을 제공하기 위해서만 이용합니다.

4. 보관 위치와 기간

선생님 브라우저의 확장앱 전용 저장소에 보관하며 외부 서버에 저장하지 않습니다. 선생님이 삭제하거나 확장앱을 삭제할 때까지 보관합니다.

5. 제3자 제공과 외부 전송

없습니다. 분석 도구, 광고, 추적 코드를 쓰지 않습니다. 확장앱이 보내는 네트워크 요청은 선생님이 누른 웨일 클래스 명단 읽기 요청(class.whalespace.io)뿐입니다.

6. 삭제 방법

  • 설정 → 모든 데이터 삭제: 저장된 모든 정보를 즉시 지웁니다.
  • 명단 → 학급 삭제: 해당 학급의 명단과 기록을 지웁니다.
  • 확장앱을 삭제하면 저장된 정보도 함께 지워집니다.

7. 아동의 개인정보

학생 대부분이 만 14세 미만일 수 있습니다. 그래서 수업에 필요한 최소한의 정보만 선생님의 기기 안에서만 처리하고, 어떤 외부로도 전송하지 않습니다.

8. 변경 · 문의

처리방침이 바뀌면 확장앱 업데이트 내역과 이 문서에 알립니다. 문의: cyeons@gne.go.kr
