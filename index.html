클래스툴 for Whale 개인정보 처리방침

최종 수정일: 2026-09-28 · 클래스툴 for Whale은 네이버가 만들거나 보증하는 공식 앱이 아닙니다.

클래스툴 for Whale(이하 "확장앱")은 선생님이 학급 도구(뽑기, 타이머 등)를 쓸 수 있도록 학생 명단을 선생님의 브라우저 안에만 저장합니다. 개발자를 포함한 누구에게도 학생 정보가 전송되지 않습니다.

1. 처리하는 정보

학생 이름웨일 클래스에 표시되는 이름(별명) 또는 선생님이 직접 입력한 이름
번호웨일 클래스의 번호(NEIS 정보 등록 시) 또는 자동으로 붙인 번호
그룹웨일 클래스 그룹 이름(있을 때)
웨일 클래스 내부 ID다시 불러올 때 같은 학생을 찾기 위한 식별 번호
도구 사용 기록뽑기·발표 기록, 모둠·역할·점수·자리 배치 결과, 타이머 설정
학교·측정소 설정급식을 볼 학교(이름·학교 코드), 미세먼지 측정소 이름
에어코리아 인증키(선택)선생님이 직접 넣은 경우에만. 이 브라우저에만 두고 백업 파일에는 넣지 않습니다

처리하지 않는 정보: 이메일, 연락처, 성적, 사진, 위치, 브라우저 방문 기록, 녹음

마이크: [소음 측정]을 켰을 때만 마이크를 씁니다. 소리의 크기만 화면 안에서 계산하고 바로 버리며, 녹음하거나 저장·전송하지 않습니다.

이름 읽어 주기: 켜 두면 뽑힌 이름 등을 소리로 읽습니다. 학생 이름이 외부 음성 서버로 가지 않도록 이 컴퓨터 안에 설치된 음성만 씁니다.

2. 수집 방법

  • 선생님이 [웨일 클래스에서 불러오기]를 누르면, 선생님이 로그인한 웨일 클래스의 구성원 관리 화면을 읽기만 합니다. 웨일 클래스의 정보를 바꾸지 않습니다.
  • 선생님이 이름을 직접 입력하거나 붙여넣을 때
  • 처음 불러오기 전에 이 내용을 안내하고 동의를 받습니다.

3. 이용 목적

학급 도구 화면에 학생 이름과 번호를 표시하고, 뽑기의 중복 제외, 골고루 참여, 기록 기능을 제공하기 위해서만 이용합니다.

4. 보관 위치와 기간

선생님 브라우저의 확장앱 전용 저장소에 보관하며 외부 서버에 저장하지 않습니다. 선생님이 삭제하거나 확장앱을 삭제할 때까지 보관합니다.

5. 제3자 제공과 외부 전송

없습니다. 분석 도구, 광고, 추적 코드를 쓰지 않습니다. 확장앱이 보내는 네트워크 요청은 아래뿐이며, 학생 정보는 어느 요청에도 들어가지 않습니다.

  • 웨일 클래스(class.whalespace.io): 선생님이 버튼을 눌렀을 때 읽기만 합니다(구성원 명단 읽기, [공지로 보내기]를 위한 공지 게시판 주소 찾기).
  • 나이스 교육정보 개방 포털(open.neis.go.kr): [급식]에서 학교를 찾고 급식 식단을 읽습니다. 학교 이름·학교 코드·날짜만 보냅니다.
  • 미세먼지: [미세먼지]에서 에어코리아(한국환경공단)의 측정값과 예보를 읽고, 학교 위치로 가까운 측정소를 찾습니다. 학교 이름·시·도·측정소 이름과 날짜만 보냅니다. 기본은 개발자가 운영하는 클래스툴 중계 서버(classtool-air.vercel.app, Vercel 서울 리전)를 거칩니다. 중계 서버는 에어코리아 인증키를 붙여 대신 조회하고 결과를 잠시 저장할 뿐, 요청 내용을 따로 기록하지 않습니다. Vercel이 서비스 운영을 위해 접속 기록(IP 주소 등)을 남길 수 있습니다. 선생님이 자기 인증키를 넣으면 중계 서버 없이 에어코리아(apis.data.go.kr)에 바로 조회하며, 인증키도 함께 보냅니다.

6. 삭제 방법

  • 설정 → 모든 데이터 삭제: 저장된 모든 정보를 즉시 지웁니다.
  • 명단 → 학급 삭제: 해당 학급의 명단과 기록을 지웁니다.
  • 확장앱을 삭제하면 저장된 정보도 함께 지워집니다.

7. 아동의 개인정보

학생 대부분이 만 14세 미만일 수 있습니다. 그래서 수업에 필요한 최소한의 정보를 선생님의 기기 안에서만 처리하고, 외부로 전송하지 않습니다.

8. 변경 · 문의

처리방침이 바뀌면 확장앱 업데이트 내역과 이 문서에 알립니다. 문의: cyeons@gne.go.kr
